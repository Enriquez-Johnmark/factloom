# @factloom/storage

The SQLite adapter for the `MemoryStore` interface in `@factloom/core`, with its SQL and its migrations. It is the only package that contains SQL.

It imports `@factloom/core` only. It enforces the rules of the schema and makes no decisions about facts.

**Status:** `openSqliteMemoryStore` opens a file, applies the migrations, writes a change set with `commit` and reads facts by structure with the time predicate. Two of the four groups of the storage contract suite run against it. The keyword and vector lanes do not exist yet.
