# Apache-2.0 licence

Status: accepted

Factloom is published under the Apache License 2.0. Anyone may use, modify and distribute it, including commercially, and contributors grant a patent licence.

It is the licence most of the comparable projects use, which removes a question for anyone evaluating Factloom next to them, and the explicit patent grant matters more for infrastructure that others build on than it would for an application.

## Considered options

- **MIT.** The same freedoms in less text, with no patent grant.
- **No licence yet.** Rejected: others could read the code but not use it.

## Consequences

The third-party skills in `.claude/skills/` keep their own licences, MIT and Apache-2.0, each recorded in its folder.
